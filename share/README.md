# NOVA-Share: התקנה במחשב ב-2 צעדים

השירות שמאפשר לטלוויזיה לנהל את "הספרייה שלי" מהמחשב, בלי חלון פתוח ובלי להגדיר כלום ידנית.

## 1. קבל את המתקין במחשב (בחר דרך אחת)

- **במחשב:** [להורדת המתקין](https://github.com/mailroni-cell/nova-access/raw/main/share/NOVA-Share-Setup.cmd) (קובץ אחד, `NOVA-Share-Setup.cmd`).
- **מהטלפון:** שלח לעצמך את הקישור ופתח אותו במחשב:
  - [שלח בוואטסאפ](https://wa.me/?text=https%3A%2F%2Fgithub.com%2Fmailroni-cell%2Fnova-access%2Ftree%2Fmain%2Fshare)
  - [שלח במייל](mailto:?subject=NOVA-Share&body=https%3A%2F%2Fgithub.com%2Fmailroni-cell%2Fnova-access%2Ftree%2Fmain%2Fshare)
  - או "שתף" רגיל של הטלפון (Gmail חוסם קבצי .cmd כקובץ מצורף, לכן שולחים קישור ולא את הקובץ).
- **בשורה אחת:** במחשב לחץ `Win+R`, הדבק ולחץ Enter:

```
cmd /c curl -L -o "%TEMP%\NOVA-Share-Setup.cmd" https://github.com/mailroni-cell/nova-access/raw/main/share/NOVA-Share-Setup.cmd && "%TEMP%\NOVA-Share-Setup.cmd"
```

## 2. הרץ ואשר

לחץ פעמיים על הקובץ ואשר "כן" כש-Windows שואל על הרשאת מנהל (פעם אחת). יופיע קוד של 6 ספרות, תקף 5 דקות.

## בטלוויזיה

הספרייה שלי ← חיפוש אוטומטי ← הקלד את הקוד. מכאן הכול נעשה מהטלוויזיה.

## הסרה

מהטלוויזיה: בדיקת תקינות ← הסרת השירות. או מהחלון במחשב. לא נשאר שום קובץ.
