NOVA-Share (service for the NOVA "My library") - S-189 2026-11-01
Download BOTH files into the same folder on the Windows PC, then double-click NOVA-Share-Setup.cmd (Windows asks once: run as administrator = Yes).
A 6-digit code appears; on the TV: My library > Search automatically > type the code.
Everything can be removed from the TV (Health check > Remove the service) or from the PC window (Remove the service). No file stays behind.
